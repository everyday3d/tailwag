# Changelog

All notable changes to **TailWag Studio** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-16

### Added
- **Core Beer-Lambert + Kubelka-Munk Optical TD Engine** (`src/engine/opticalTdEngine.ts`) with real-time per-layer composite color lookup tables and CIE LAB $\Delta E$ perceptual metrics (Fixes #1).
- **Interactive Three.js 3D Filament Painting Viewport** (`src/components/Viewport3D.tsx`) featuring split-screen source wipe comparison, studio key-light azimuth/elevation controls, X-ray layer cutaway scrubber, and Front-Lit vs. Back-Lit Lithophane mode (Fixes #1).
- **AI Palette & Layer-Swap Auto-Solver** (`src/engine/autoSolver.ts`) generating optimal true-tone, BoxerDawg warm portrait pop, and archival monochrome recipes from owned AMS spools or full brand catalog (Fixes #1).
- **2.5D Parametric CAD Shape, Frame, Clock & Cutout Engine** (`src/engine/cadMeshBuilder.ts`) supporting circular/rounded/hexagonal/shield/medallion silhouettes, beveled/stepped 3D frames, HueForge Wall Clock shaft bores + rear movement pockets + raised stencil numerals, keychain holes, and rear neodymium magnet pockets (Fixes #1).
- **Native Bambu Studio / OrcaSlicer `.3MF` Exporter & Single-AMS Swap Playbook** (`src/engine/exporter3mf.ts`) packaging watertight meshes, filament hex palettes, 100% rectilinear infill settings, height-range modifiers, and `>4 Color Single-AMS Chaining` instructions (Fixes #1).
- **Built-in TD Calibrator & Live Bambu Fleet Studio AMS Sync** (`src/components/TdCalibratorModal.tsx`) with 16-step calibration wedge `.STL` export and Home Assistant `bambu_fleet_studio` AMS tray synchronization (Fixes #1).
- **TailWag Model Context Protocol (MCP) Server** (`mcp/server.ts`) exposing `tailwag_list_filaments`, `tailwag_solve_palette`, `tailwag_simulate_layer_stack`, `tailwag_export_3mf_project`, and `tailwag_calibrate_td` for autonomous AI agent solving (Fixes #1).

- **Filament Library: Manufacturer Catalog, Searchable Picker, Manual Add Form & TD Source Tracking** (`src/data/manufacturerCatalog.ts`, `src/engine/tdPrior.ts`, `src/utils/myLibrary.ts`, `src/components/FilamentLibraryModal.tsx`, `src/store/useTailWagStore.ts`, `src/App.tsx`): Added a bundled, versioned, offline manufacturer catalog (Bambu Lab, Polymaker, eSun, Elegoo, Sunlu, Hatchbox, Overture, Prusament, Creality) with approximate colors from public charts; a searchable picker filtered by brand, material, color name, hue family and TD range; a manual add form (color picker, screen eyedropper, TD with prior suggestion and plausibility warning, optional AMS slot, duplicate check); a persistent **My Filaments** library; and per-spool TD source tracking (`Measured` > `User-entered` > `Catalog` > `Estimate`) with badges in the library list. TD estimates come from a hue/lightness prior and never overwrite a stronger source. Each catalog entry has a prefilled GitHub issue link for corrections (Refs #24).

- **PrintPlan: One Source of Truth for Preview and Exports** (`src/engine/printPlan.ts`, `src/engine/exporter3mf.ts`, `src/components/Viewport3D.tsx`, `src/components/ExportModal.tsx`, `src/App.tsx`): Added a `PrintPlan` built once from the heightmap, layer settings and swap slots. It holds the printed layer count of every pixel (using the slicer mid-plane rule on the exported Z), the filament bands with exact Z ranges, the predicted color per layer, and a stable hash. The 3D viewport now reads layers and colors from the plan instead of re-deriving them from luminance, and the fake alternating layer shading was removed so the preview shows the prediction. The swap playbook and the 3MF band Z limits come from the same band logic; Z values are snapped to 4 decimals. The 3MF and the no-AMS bundle embed `TailWag_PrintPlan.json` and a Print Plan ID, the Export dialog shows the ID, and an export is blocked with an explanation if the plan is stale (Refs #25).

- **TD Provenance Corrections** (`src/utils/myLibrary.ts`, `src/store/useTailWagStore.ts`, `src/data/manufacturerCatalog.ts`, `DATA_SOURCES.md`): The original ~50 catalog spools, whose TD origin was never recorded, are now labeled `Estimate` (values unchanged). The bundled personal library, measured by the owner with a TDS1, loads as `Measured`; other imported libraries load as `User-entered`. Legacy saved libraries are migrated on load. The personal library was audited for personally identifying information and approved for public releases (Refs #32).

- **Edit Filament, Catalog Provenance & Data Licensing Policy** (`src/components/SpoolEditModal.tsx`, `src/store/useTailWagStore.ts`, `src/utils/myLibrary.ts`, `src/data/manufacturerCatalog.ts`, `DATA_SOURCES.md`, `.github/ISSUE_TEMPLATE/filament-data.yml`): Added an Edit dialog for any filament (name, brand, line, material, color, TD, TD source, AMS slot) with delete for My Filaments spools. Editing a spool that is in the layer stack updates the stack and re-tunes swap layers when color or TD changes. Replacing a stronger TD source requires an explicit choice and shows a warning. Catalog entries now carry a per-brand `sourceUrl` (brand names link to the manufacturer page to verify), a test enforces provenance on every entry, `DATA_SOURCES.md` records data origin and the third-party import-only policy, and a `filament-data` issue template and label support corrections (Fixes #24).

- **Library Filters: AMS Slot, Stock Status (Low / Out) & TD Sorting** (`src/utils/libraryView.ts`, `src/App.tsx`, `src/utils/filamentJsonIO.ts`, `src/data/filamentCatalog.ts`): Added AMS slot filter (all, loaded in AMS, not in AMS, or an exact slot), stock filter (any, available, in stock, low, out), and sorting by TD (low to high, high to low), dark to light, name or brand. Each spool has a clickable stock chip that cycles In stock, Low, Out; spools marked Out are excluded from the auto-solver pool. Stock status, TD source and AMS slot are preserved in library JSON export and import (Refs #24).

- **JSON Filament Library Importer, `Owned` vs `All Catalog` Top Tabs & Auto-Solver Pool Selector** (`src/utils/filamentJsonIO.ts`, `src/store/useTailWagStore.ts`, `src/App.tsx`): Added 1-click `.json` filament library import/export supporting both HueForge (`Filaments`, `Transmissivity`, `Color`, `Brand`, `Name`, `Type`) and TailWag schemas with `localStorage` persistence, a dedicated top tab bar (`Owned` vs `All Catalog`) in the Filament Library, and an explicit Auto-Solver Filament Source selector (`Owned` vs `Currently Shown`) (Fixes #5).
- **Loaded `.JSON` Library Manager (`Remove Library`), `4 / 8 / 12 / 16` Color Stack Solver & Real-Time Slider Preview** (`src/engine/autoSolver.ts`, `src/components/Viewport3D.tsx`, `src/components/LayerTimeline.tsx`, `src/store/useTailWagStore.ts`, `src/App.tsx`): Pre-aggregated image samples into 24-layer CIE LAB buckets and pruned midtone combinatorial search so 181+ spool `.json` libraries (`filaments.json`) solve in `< 5ms` instead of freezing; added a **`Remove`** button for each imported `.json` library; added `4 / 8 / 12 / 16 Colors` palette stack options; and split Three.js mesh topology from in-place `Float32BufferAttribute` updates so every slider updates the 3D preview in real time (Fixes #6).
- **Input Validation Guardrails, Impossible Palette Feasibility Diagnostics, Metadata JSON Export & Vectorized Delta E Engine** (`src/engine/hueForgeAutoEngine.ts`, `scripts/hueforge_vectorized.py`): Automatically downsamples and normalizes input images to $\le 256\text{px}$ preserving aspect ratio to avoid memory overflow during multi-pass optimization, and validates sRGB gamma transfer; throws descriptive `HueForgePaletteError` when user inventories lack dark contrast shadow anchors ($L^* < 30$), preventing muddy washed-out prints; exports structured HueForge-compliant metadata JSON with exact Z-axis swap heights and slicer pause instructions; provides a visual side-by-side comparison generator (Target Image vs. Simulated Optical Stacking Preview); and vectorizes pixel matching and CIEDE2000 calculations across typed arrays and NumPy/SciPy computing over 7.3 million pixels/sec via array broadcasting (Fixes #10).
- **Standardized 246x246mm Bed Bounding Box, Fixed 0.16mm/0.08mm Layer Architecture, 7-Slot Dual-AMS Mapping & Blend Depth Controls** (`src/engine/layerSliceConverter.ts`, `src/engine/hueForgeAutoEngine.ts`, `src/store/useTailWagStore.ts`, `src/App.tsx`): Defaulted all relief mesh output bounding box dimensions to the standard Bambu Lab 246x246mm build plate envelope, maintaining aspect ratio without letterboxing or distortion; hardcoded physical slicing geometry to 0.16mm robust base layer + uniform 0.08mm micro-layers for smooth optical gradient stacking; added support for scaling palette pools up to 7 distinct filaments across dual-AMS hardware (AMS 1 Slots 1-4 and AMS 2 Slots 1-3, leaving 1 slot open for support or purge spools) with monotonic Z-band grouping (at most $N-1$ swaps, eliminating ping-pong toolhead purges) and ~240 mm³/swap purge economy tracking; added adjustable parameters for Base Thickness (0.48mm–0.80mm) and Max Mesh Height (2.0mm–2.4mm) with dynamic blend depth calculation ($Z_{max} - Z_{base}$) (Fixes #11).

- **Universal CIE LAB K-Means++ Color Quantization Engine, `0.16mm / 0.08mm` HueForge TD Layer Blending & Smart 4-Color Advisory** (`src/engine/colorQuantizerEngine.ts`, `src/engine/autoSolver.ts`, `src/engine/opticalTdEngine.ts`, `src/engine/cadMeshBuilder.ts`, `src/engine/exporter3mf.ts`, `src/App.tsx`): Added a deterministic K-Means++ & CIEDE2000 ($\Delta E_{00}$) color quantization engine with Coordinate-Descent Beer-Lambert swap-height optimization across all hues; standardized on HueForge's `0.16mm` Initial Layer + `0.08mm` Layer Height + `100%` Rectilinear Infill (`999` solid shells) + Black starting base layers (`0.48mm` minimum base depth); separated `CMYK Mode` into an independent solver mode; and added an automatic UI advisory banner when `<= 4` colors already capture the image's color and tonal gamut.
- **Landscape Spatial Denoising, Bilateral Heightmap Filtering, Gradient Continuity & Restrictive Dominance Pruning** (`src/engine/cadMeshBuilder.ts`, `src/engine/layerSliceConverter.ts`, `src/engine/autoSolver.ts`, `src/engine/colorQuantizerEngine.ts`, `src/engine/hueForgeAutoEngine.ts`): Eliminated splotchy noise, erratic height spikes, and fragmented color assignments in high-detail landscape photos:
  1. *Spatial Coherence / Bilateral Filtering on Height Maps*: Implemented `applyBilateralHeightmapFilter` ($\sigma_s = 1.8$, $\sigma_r = 0.08$, $5\times 5$ window) into CAD mesh grid generation, layer slicing, and auto-engine luminance processing, smoothing random background micro-spikes (leaves, gravel, pavement roughness) while preserving sharp step edges and silhouettes.
  2. *Gradient Preservation & Banding Prevention*: Added `computeGradientBandingPenalty` and adjacent micro-layer banding prevention ($< 2$ layers / $0.16\text{mm}$) into the Beer-Lambert stack evaluation cost function, disallowing abrupt contrasting filament swaps across adjacent micro-layers in smooth scenic gradients (like canopy transitions and road surfaces) unless backed by a sharp structural silhouette edge ($\text{edgeStrength} \ge 0.35$).
  3. *Restrictive Cluster Dominance for Palette Selection*: Enforced regional cluster dominance ($\ge 2\%$ of active image area), automatically merging non-dominant low-chroma micro-clusters into the nearest dominant midtone to prevent stray speckling (such as random dark/green spots on asphalt roads) while strictly preserving intentional ultra-saturated graphic accents ($\text{chroma} \ge 45$ and $\ge 0.35\%$ area) (Fixes #12).
- **Morphological Region Merging, Discrete Layer Quantization Banding & Structural Gradient Smoothing** (`src/engine/cadMeshBuilder.ts`, `src/engine/layerSliceConverter.ts`, `src/engine/hueForgeAutoEngine.ts`): Eliminated high-frequency pixel speckling and digital static across the height-map and layer slicing pipeline:
  1. *Morphological Filtering & Region Merging*: Added `applyMorphologicalRegionMerge` using 4-connected component blob analysis and perimeter neighbor frequency weighting to merge isolated pixel speckles smaller than `< 4` adjacent pixels into their surrounding dominant region while preserving legitimate linear and structural details.
  2. *Height-Map Quantization Banding*: Added `quantizeHeightmapMatrix` to snap continuous float heights cleanly to discrete layer-height intervals (0.08mm steps) using a rounded quantization matrix before multi-layer splitting, stopping float micro-fluctuations from generating single-pixel peaks.
  3. *Spatial Gradient Smoothing*: Added `applySpatialGradientSmoothing` with Sobel edge masking (`computeSobelEdgeMask`), penalizing sudden height discontinuities between immediate neighbor pixels in smooth regions while strictly preserving crisp structural silhouette boundaries ($\text{edgeThreshold} \ge 0.35$) (Fixes #14).
- **CIELAB Chroma Scaling, Histogram Spacing Constraint & Upper-Layer Highlight Clamp Logic** (`src/engine/colorQuantizerEngine.ts`, `src/engine/hueForgeAutoEngine.ts`, `src/engine/autoSolver.ts`): Prevented muted/washed-out results and hue bleed on colorful photos:
  1. *CIELAB Chroma Scaling*: Implemented `scaleLabChroma` applying a dynamic $1.30\times$ scalar multiplier to $a^*$ and $b^*$ chromaticity channels post-conversion prior to CIEDE2000 $\Delta E$ calculations, while shielding shadow noise ($L < 22, C < 6.0$) and capping skin tones / fawn fur ($20^\circ \le h \le 78^\circ$) to $1.08\times$ to avoid artificial orange oversaturation.
  2. *Histogram Spacing Constraint*: Added angular hue distance spacing (`getHueAngularDistanceDeg`, $25^\circ$ threshold) in K-Means cluster merging and penalized duplicate neutral/gray midtones ($+50.0$) in palette selection unless explicitly overridden via `manualNeutralOverride: true`, ensuring diverse chromatic representation across the source image histogram.
  3. *Highlight Clamp Logic*: Added `isLowTdGreenOrDarkPigment` optical classification and strict upper-layer assignment constraints, clamping low-TD green ($TD < 4.0\text{mm}$) and dark pigments ($L < 42$ or $TD < 2.0\text{mm}$) from occupying the final top 4 micro-layers ($l \ge \text{totalLayers} - 4$) with a $+5000.0$ penalty in coordinate descent, guaranteeing clean warm highlights and specular caps (Fixes #16).
- **Detail-Preserving Edge Sharpening, Adaptive Quantization Banding & Contrast-Stretched Z-Depth Allocation** (`src/engine/cadMeshBuilder.ts`, `src/engine/layerSliceConverter.ts`, `src/engine/hueForgeAutoEngine.ts`, `src/engine/autoSolver.ts`): Eliminated the blocky, washed-out look and restored crisp sharpness across fine micro-details:
  1. *Detail-Preserving Edge-Aware Sharpening*: Implemented `applyEdgeAwareHeightmapSharpening` using Sobel gradient magnitude and an adaptive coring ramp (threshold: $0.02$, strength: $0.85$, max overshoot clamp: $0.15$) to amplify high-pass detail on tree trunks, branches, fine silhouettes, and sharp boundaries without boosting flat sensor noise.
  2. *Adaptive Quantization Banding Control*: Replaced flat block quantization with `adaptiveQuantizeHeightmapMatrix` and edge-protected `applyMorphologicalRegionMerge`. Allows tighter, continuous micro-elevation in high-contrast/high-detail zones ($G \ge 0.08$) while reserving discrete layer snapping for flat backgrounds, preserving thin 1–3 pixel features from being flattened into staircase terraces.
  3. *Contrast-Stretched Dynamic Range Allocation*: Re-normalized the heightmap histogram dynamically so that shadow anchors utilize base layer 1 ($0.16\text{mm}$) and highlights reach the maximum physical Z-height limit, preventing midtone compression and utilizing 100% of the available relief Z-depth (Fixes #18).
- **Dynamic 6-to-8 Filament Allocation, Uncoupled Structural Height-Map Processing & Chroma-Weighted Delta E Scoring** (`src/engine/autoSolver.ts`, `src/engine/cadMeshBuilder.ts`, `src/engine/hueForgeAutoEngine.ts`): Maintained high color fidelity while preserving sharp structural edge contours:
  1. *Dynamic 6-to-8 Filament Allocation for Complex Scenes*: For high-contrast landscape and foliage scenes, restricted the auto-solver from dropping below 6 active AMS slots on multi-AMS setups (allocating 6 to 8 spools) and enforced a minimum palette distribution guaranteeing 1 dark base, 2 transition midtones (prioritizing essential image hues like foliage green and earth brown), 2 vibrant warm highlights (yellows and oranges), and 1 high-TD white cap.
  2. *Uncoupled Edge-Map and Color-Map Processing*: Separated physical structural height-map generation (`structuralHeightmap`) from the color-assignment matrix (`finalColorLum` / `smoothedLum`). Physical 3D relief contours (tree trunks, branch edges, silhouettes, road boundaries) are generated directly from enhanced luminance via edge-aware unsharp masking, preventing bilateral and spatial color smoothing filters from eroding physical geometry.
  3. *Chroma-Weighted Delta E Scoring*: Updated the Beer-Lambert optimization cost function and coordinate descent boundary optimizer to apply priority weighting ($1.8\times$ up to $3.5\times$) to color accuracy ($\Delta E_{00}$) in the warm spectral range (oranges, yellows, warm golds) while attenuating flat neutral background error ($0.85\times$) and scaling warm cluster coverage error ($2.5\times$), ensuring vibrant focal points are never muted out by neutral background dominance (Fixes #20).
- **Reactive Live 3D Re-Rendering & Automatic Layer Swap Optimization on Spool or Order Change** (`src/store/useTailWagStore.ts`, `src/components/Viewport3D.tsx`, `src/components/LayerTimeline.tsx`, `src/App.tsx`, `src/engine/autoSolver.ts`):
  1. *Automatic Swap Boundary Optimization*: Whenever a user changes a filament spool in any slot (via dropdown selector or library drop) or rearranges the lay-down sequence (via left/right or up/down arrows or card dragging), `useTailWagStore` automatically re-solves optimal layer swap boundaries (`optimizeManualSlotBoundaries`) against the active image data using coordinate descent and Beer-Lambert transmission modeling, while respecting locked slots.
  2. *Immediate 3D Relief & Timeline Re-Rendering*: Synchronized `renderVersion` across `useTailWagStore`, `Viewport3D`, and `LayerTimeline`, forcing Three.js to immediately update vertex colors (`colAttr.needsUpdate = true`) and render the updated optical stack, while automatically switching `viewportMode` to `'3d-mesh'` if currently on `'source'`.
  3. *Synchronized Manual Mode & Direct Palette Selection*: Centralized `solverColorMode` in the store, automatically transitioning to `'manual'` mode on user customization so custom palettes are preserved, and added quick `<select>` dropdowns to the sidebar manual palette cards matching `LayerTimeline` (Fixes #22).
